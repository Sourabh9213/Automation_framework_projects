# ✈️ BlazeDemo Automation Project

## 📌 Project Overview
This project automates the BlazeDemo flight booking application using Selenium, Java, TestNG, and Maven.

---

## 🛠️ Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Extent Reports
- Apache POI (Excel Handling)

---

## 📂 Project Structure
- `pages` → Page Object Model classes  
- `tests` → Test cases  
- `utils` → Utility classes (Excel, Reports)  
- `testData.xlsx` → Test data  

---

## ✅ Test Scenarios Covered
- Home page validation  
- Flight search (dynamic cities)  
- Flight selection  
- Booking flow (data-driven)  
- Negative scenarios (blank form, invalid data)  
- Confirmation page validation  

---

## 📊 Features
- Data-driven testing using Excel  
- Page Object Model (POM)  
- Extent Reports integration  
- TestNG XML execution  
- Group execution (Smoke, Regression, Sanity)  

---

## ▶️ How to Run
1. Clone the repository  
2. Open project in Eclipse  
3. Right click on `testng.xml`  
4. Select **Run As → TestNG Suite**

---

## 🧠 Notes
- BlazeDemo is a demo site, so validations are limited  
- Negative test cases are based on system behavior
