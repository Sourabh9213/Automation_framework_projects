# 🧪 Automation Testing Framework - bstackdemo.com

## 📌 Project Overview
This project is a **Selenium Automation Framework** developed using **Java, TestNG, and Maven** to automate testing of an e-commerce application.

The application under test:
🔗 https://bstackdemo.com/

This framework is designed to be **scalable, maintainable, and reusable** using Page Object Model (POM).

---

## 🧠 Objective
To automate core functionalities of the e-commerce platform including:
- Login
- Product selection
- Cart operations
- Checkout process

---

## 🛠️ Tech Stack

| Tool | Purpose |
|------|--------|
| Java | Programming Language |
| Selenium WebDriver | Browser Automation |
| TestNG | Test Execution |
| Maven | Build Management |
| ExtentReports | Reporting |
| Git/GitHub | Version Control |

---

## 🏗️ Framework Architecture

- **Design Pattern**: Page Object Model (POM)
- **Listener**: ITestListener for reporting & logging
- **Reporting**: ExtentReports with screenshots
